# Путешествия 2026–2027 — общий сайт

Витрина всех поездок сезона: большие фото, даты, ведущие, цены, кнопки «Записаться» (Telegram с готовым текстом) и «Подробнее» (сайт поездки).

## Файлы

- `index.html` — готовый сайт, открывается без сборки.
- `img/` — фото поездок и `og.jpg` для превью ссылки в Telegram.
- `content.json` — все тексты, даты, цены и ссылки.
- `build.py` — пересобирает `index.html` из `content.json`.

## Как поменять текст или добавить поездку

1. Правка в `content.json` (новая поездка = новый блок в `tours`, фото кладётся в `img/<id>.jpg`).
2. `python3 build.py`
3. Коммит и пуш.

Бейдж «Старт через N дней» считается сам по сегодняшней дате. Прошедшие поездки помечаются «Состоялось».

## Публикация на GitHub Pages

1. Новый репозиторий в `utromaya-code`, содержимое папки в корень ветки `main`.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Свой домен: файл `CNAME` с доменом, в DNS четыре A-записи
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   и CNAME `www` → `utromaya-code.github.io`. Затем Enforce HTTPS.
4. В `content.json` вписать `meta.siteUrl` (например `https://домен.ru`) и пересобрать,
   чтобы превью ссылки брало картинку по полному адресу.
