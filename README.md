# Путешествия 2026–2027 — общий сайт

Витрина всех поездок сезона: большие фото, даты, ведущие, цены, кнопки «Записаться» (Telegram с готовым текстом) и «Подробнее» (сайт поездки).

## Файлы

- `index.html` — готовый сайт, открывается без сборки. Руками не правится: его собирает `build.py`.
- `404.html` — страница «Такой страницы нет» для неверных адресов, её тоже собирает `build.py` (тексты в `notFound`).
- `variant-1.html`, `variant-2.html`, `variant-3.html` — черновики позиционирования для обсуждения: другой первый экран, фраза-манифест и «Как мы путешествуем» вместо «Почему с нами». Собираются из `previews` в `content.json`, закрыты от поисковиков, с основной страницы на них ссылок нет. Когда вариант выбран, его тексты переносятся в `hero`, `brand`, а `previews` можно удалить.
- `content.json` — все тексты, даты, цены, места, ссылки и отзывы.
- `build.py` — пересобирает `index.html` из `content.json`, ничего ставить не нужно.
- `images.py` — готовит картинки: WebP-версии фото, иконки сайта и `img/og.jpg` для превью ссылки в Telegram. Нужен Pillow (`pip install pillow`).
- `img/` — исходные фото (`<id>.jpg` поездок, `moment-*.jpg` для «Как это было», `team-*.jpg`) и их WebP-версии.
- `fonts/` — шрифты сайта: Unbounded, Onest, IBM Plex Mono с Google Fonts, лицензии OFL рядом.
- `tools/fonts/` — Unbounded для картинки превью, им пользуется `images.py`.
- `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` — иконки сайта.

## Как поменять текст или добавить поездку

1. Правка в `content.json` (новая поездка = новый блок в `tours`, фото кладётся в `img/<id>.jpg` шириной от 1920 px, лучше 2400: иначе на ретина-экранах оно будет мягким).
2. Если поменялись фото, `pos`, снимки галереи или команды, текст превью `og`: `python3 images.py`.
3. `python3 build.py`
4. Коммит и пуш.

Бейдж «Старт через N дней» считается сам по сегодняшней дате. Прошедшие поездки помечаются «Состоялось».

Где что в `content.json`: `hero` — первый экран, `hot` — блок «Места заканчиваются», `dock` — плашка внизу экрана на телефоне, `tripNav` — подпись строки поездок, `gallery` — снимки прошлых поездок «Как это было», `about.since` и `about.sinceLabel` — большая цифра в «О нас» и подпись к ней, `about.team` — команда, `contact` — блок контактов (`photo` — фон блока), `og` — текст на картинке превью.

У поездки `seats` — места (при `left: 1` поездка выделяется как «Последнее место»: флажок на фото, синий блок в правой колонке, строка в «Места заканчиваются»), `callout` — плашка в правой колонке, когда число мест не показываем, например `{"title": "Регистрация по ранней цене", "text": "Займите своё место."}`. На первом экране только название и месяц, места показываются внутри поездки.

У поездки `pos` — какая точка фото остаётся в кадре, `spinePos` (необязательно) — то же для узкой полосы на первом экране, если там нужна другая часть кадра (у Дахаба так видно фридайвера целиком).

## Галерея «Как это было»

Список `gallery.items`, один снимок:

```json
{"img": "moment-bhutan-yaks", "ratio": "4:5", "pos": "50% 60%", "cap": "Бутан · яки на горной дороге", "alt": "Описание для незрячих"}
```

Файл `img/<img>.jpg`, `ratio` — пропорция кадра (3:2, 4:5, 2:1), `pos` — какая точка остаётся при кадрировании. На широком экране снимки идут рядами по четыре одной высоты; ровнее всего, когда в каждой четвёрке два горизонтальных и два вертикальных кадра (или один 2:1 и три вертикальных), как сейчас. После правки `python3 images.py`, затем `python3 build.py`.

## Команда

`about.team`: `img` (файл `img/team-*.jpg`, кадр 4:5 по точке `pos`), `name`, `role`, `bio`. Необязательная строка `about.guests` выводится под командой (например, приглашённые ведущие), сейчас её нет.

Блоки при прокрутке мягко проявляются один раз (класс `rv`); без JS и при отключённых анимациях всё видно сразу. Ссылка на сайт поездки в правой колонке: текст `tripLink` и `domain` поездки. Подпись в шапке: `brand`.

## Отзывы

Список `reviews` в `content.json`. Пока он пустой, секции «Что говорят участники» на сайте нет. Один отзыв:

```json
{"name": "Имя", "trip": "Тибет, 2025", "text": "Текст отзыва", "photo": "review-anna"}
```

`photo` необязательно: это файл `img/review-anna.jpg`, квадратный, от 200 px. После добавления фото `python3 images.py`, затем `python3 build.py`.

## Картинки

- Все фото проходят одну цветокоррекцию (`grade` в `images.py`), чтобы снимки с разных камер и поездок смотрелись одной серией.
- Фото поездки отдаются в нескольких размерах, браузер выбирает по ширине и плотности экрана: на телефоне вертикальный кадр 4:5 (`<id>-800.webp`, `<id>-1200.webp`), на широком экране полное фото (`<id>-1440.webp`, `<id>-2400.webp` для ретины). Версии 1200 и 2400 появляются, только если исходник достаточно большой. Вертикальный кадр вырезается по точке `pos`, поэтому после смены `pos` нужен `images.py`. Шумные кадры слегка сглаживаются; если исходник пересвечен по резкости (ореолы вокруг травы и листьев), у поездки ставится `soften` (например `0.6`), как у Бали.
- Снимки галереи: 360/640/960 px, команда: 400/800 px, браузер берёт нужный размер сам.
- Фото-полосы и первая глава грузятся сразу, остальные фото по мере прокрутки.
- Если WebP для поездки ещё нет, страница берёт исходный JPEG, так что новая поездка не сломается.

## Публикация на GitHub Pages

1. Новый репозиторий в `utromaya-code`, содержимое папки в корень ветки `main`.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Свой домен: файл `CNAME` с доменом, в DNS четыре A-записи
   `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   и CNAME `www` → `utromaya-code.github.io`. Затем Enforce HTTPS.
4. В `content.json` вписать `meta.siteUrl` (например `https://домен.ru`) и пересобрать,
   чтобы превью ссылки брало картинку по полному адресу.
