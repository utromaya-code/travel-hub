**Цель страницы:** заявка как можно раньше. Каждое изменение проверяй вопросом: станет ли человеку проще и быстрее написать «хочу поехать»?

## 1. Что в папке

| Файл | Что это |
| --- | --- |
| `index.html` | Готовая страница. Её не правь руками: она собирается скриптом |
| `content.json` | Все тексты, даты, цены, места, команда, вопросы. Единственный источник правды |
| `build.py` | Собирает `index.html` из `content.json`: `python3 build.py` |
| `img/` | Фото поездок (`<id>.jpg`), команды (`team-*.jpg`), прошлых поездок (`past-*.jpg`), превью ссылки `og.jpg` |
| `.git/` | История коммитов уже есть, ветка `main` |
| `.nojekyll` | Нужен для GitHub Pages |

Структура страницы сверху вниз:
1. Первый экран: заголовок «Комфорт забывается. Впечатления остаются.», лид, кнопка «Помочь с выбором».
2. Блок «Места заканчиваются» со списком горящих поездок.
3. Семь вертикальных фото-полос по месяцам. Цифра в кружке показывает, сколько мест осталось.
4. «Почему с нами»: шесть пунктов.
5. Семь глав-поездок. В каждой фото, описание, факты, счётчик мест, лестница цен (продано / сейчас / потом), кнопки «Забронировать место» (Telegram с готовым текстом) и «Подробнее о поездке».
6. «О нас»: 2009, текст, фото прошлых поездок, команда.
7. «Частые сомнения»: аккордеон из семи вопросов.
8. «Места заканчиваются быстро»: Telegram и WhatsApp.

Бейджи «Старт через N дней», «Идёт сейчас» и «Состоялось» считаются в браузере по текущей дате.

## 2. Шаг 1. Опубликовать (сделать сразу)

1. Создай публичный репозиторий `utromaya-code/travel-hub` без README и лицензии.
2. Запушь готовую историю:
   ```bash
   git remote add origin https://github.com/utromaya-code/travel-hub.git
   git push -u origin main
   ```
3. Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.
4. Дождись сборки и открой https://utromaya-code.github.io/travel-hub/. Проверь, что видны фото, кнопки ведут в Telegram и на сайты поездок, а в консоли нет ошибок.
5. Пришли Андрею ссылку.

Свой домен пока не подключай, его выберут позже. Когда домен появится:
- файл `CNAME` с доменом;
- в DNS четыре A-записи `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` и CNAME `www` → `utromaya-code.github.io`;
- Enforce HTTPS;
- в `content.json` поменять `meta.siteUrl`, пересобрать и запушить.

## 3. Шаг 2. Улучшения

Все тексты и данные бери из `content.json` и правь их там же. Новые блоки тоже описывай в `content.json` и выводи через `build.py`, без захардкоженного текста в шаблоне. После каждой правки: `python3 build.py`, проверка, коммит.

### 3.1. Делать сейчас, данные не нужны

**А. Первый экран на десктопе.** При окне 1440×900 фото-полосы должны целиком помещаться в первый экран. Сейчас они обрезаны снизу. Уменьши вертикальные отступы и размер h1 на широких экранах или поставь полосы рядом с заголовком. Цель: человек сразу видит, что поездок семь и они красивые.

**Б. Полосы на телефоне.** На ширине 390 px семь полос по 45 px слишком узкие. На экранах уже 760 px сделай горизонтальную ленту с прокруткой (scroll-snap). Карточка шириной около 70% экрана: фото, название, месяц, кружок с местами. Лента прокручивается пальцем, а страница вбок не уезжает. На десктопе оставь как есть, с раскрытием при наведении.

**В. Липкая кнопка на телефоне.** Внизу экрана, только на ширине до 760 px и только после того, как первый экран прокручен: короткая плашка «Места заканчиваются» и кнопка «Помочь с выбором» (тот же Telegram-линк, что в первом экране). Учитывай `env(safe-area-inset-bottom)`. Плашка не должна перекрывать кнопки в самом низу страницы: прячь её, когда виден блок контактов.

**Г. Быстрая навигация по поездкам.** Когда человек прокрутил до глав-поездок, сверху появляется тонкая липкая строка с месяцами и названиями (Дахаб · Патагония · …), текущая поездка подсвечена. Используй `top: env(safe-area-inset-top, 0px)` и IntersectionObserver. На телефоне строка прокручивается вбок.

**Д. Фото и скорость.**
- Сделай из каждого фото WebP в двух размерах (около 800 и 1440 px по ширине) и отдавай через `image-set()` для фонов и `srcset` для `<img>`. Цель: страница на телефоне весит меньше 1,5 МБ (сейчас фото весят около 2,4 МБ).
- Первое фото главы «Дахаб» и все фото-полосы грузятся сразу, остальное лениво.
- Добавь favicon (простая буква или знак в фирменном синем `#1D3EC4`, SVG + PNG 180×180 для iOS).
- Пересобери `img/og.jpg` 1200×630: семь полос, поверх крупно «Путешествия 2026–2027» и строка «С 2009 года · семь маршрутов». Шрифт Unbounded.

**Е. Мелочи вёрстки.**
- В главах-поездках выровняй правую колонку (места, цены, кнопки) по верху описания на всех ширинах.
- Проверь, что на ширине 360 px ни один бейдж на фото не наезжает на соседний и шапка не переносится.
- `prefers-reduced-motion`: никаких анимаций раскрытия и плавной прокрутки.
- Тёмная тема уже есть. Проверь новые элементы в обеих темах.

**Ж. Отзывы (каркас).** Добавь в `content.json` поле `reviews` (массив: `name`, `trip`, `text`, `photo` необязательно) и секцию «Что говорят участники» между «О нас» и «Частыми сомнениями». Пока массив пустой, секция не выводится. **Не выдумывай отзывы.** Текст будет только от Андрея.

## 4. Правила, которые нельзя нарушать

- **Не выдумывай факты.** Цены, места, даты, сроки возврата, отзывы и биографии бери только из `content.json` или от Андрея. Если чего-то не хватает, спроси, а не подставляй.
- **Тексты:** тёплый прямой русский, без длинных тире (вместо них запятая, двоеточие или точка), без эзотерических штампов и давления. Конкретные детали лучше общих слов. Слов «турпутёвка» и «туроператор» не используем.
- **Кнопка записи** везде ведёт в Telegram `https://t.me/vsemaya?text=...` с готовым текстом про конкретную поездку. Этот механизм не ломай.
- **Дизайн-система:** шрифты Unbounded (заголовки), Onest (текст), IBM Plex Mono (подписи и цифры). Акцент синий `#1D3EC4` (в тёмной теме `#8CA1FF`), фон `#F0F3F2` (тёмный `#0B1011`). Цвета только через CSS-переменные в `:root`. Новые цвета не добавляй без нужды.
- **Скорость и адаптив:** страница работает с 360 px, ничего не уезжает вбок, всё доступно с клавиатуры.
- **Фото:** подписи к фото с Wikimedia Commons (Бали, Яншо, Кайлас) в подвале не удаляй, это требование лицензии.
